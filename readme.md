# Parte A - Mondrian

Neste trabalho, o objetivo foi reproduzir uma parte da obra de Mondrian, procurando aproximar a composição criada da imagem original. Para desenvolver a reprodução, comecei por analisar os elementos presentes na imagem, identificando as formas, as suas posições e as proporções entre elas. A partir dessa análise, defini as medidas e as coordenadas necessárias para construir a composição no espaço de desenho. Também tive em conta a escolha das cores, procurando manter uma relação visual com a referência. Ao longo do processo, ajustei as posições e as dimensões dos elementos para conseguir um resultado mais próximo do original. Este exercício permitiu-me explorar a utilização de código para representar visualmente uma imagem e compreender melhor a importância das coordenadas, das proporções e das cores na construção de uma composição.
